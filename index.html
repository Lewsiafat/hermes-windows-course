AgentVibe

AI Agent 養成課 — 從「它到底是什麼」到「它每天替你打工」

你不缺 AI，你缺的是「知道自己在幹嘛」

大部分人用 AI 的方式，是對著黑盒子燒香拜拜——靈驗就截圖發文，不靈就罵它笨。

AgentVibe 是一條完整的養成路線：先搞懂 LLM 這頭「文字接龍怪獸」的真面目， 再親手裝起一個真正的 AI Agent、把它接進你的 Telegram / LINE， 教它排程、造 skill、每天早上自動交報告，最後用 vibe coding 做出真正屬於你的工具。 不用會寫程式才能開始，但走完之後，你會比 90% 的 AI 使用者更知道自己在跟什麼東西講話。

先懂再上手 · 觀念三部曲

所有課程的起點。沒上這三堂就往下衝，等於還沒學會看地圖就出海——依序上完，你會知道自己接下來每一步在幹嘛。

① LLM 101 · 文字接龍怪獸解剖課

你每天聊天的那個 AI，其實不會思考——它在賭下一個字。一小時互動課程講清楚 LLM 的真面目：巨大字典比喻、一句話進去之後發生的事、ChatGPT 跟裸模型差在哪。保證零數學、零公式。

⏱ 60 分鐘 · 6 個章節 · 互動實驗

從這裡開始

② AI Agent 101 · 給天才裝上手腳

懂了 LLM 只會出一張嘴之後，下一步就是搞懂「Agent」到底是什麼多出來的東西。用 Agent Loop、Tool Use 拆解一個修 bug 任務，順便破解「ChatGPT 就是 Agent」的誤解——模型是廚師手藝，Agent 框架才是整套餐廳 SOP。

⏱ 60 分鐘 · 7 個章節 · 互動 Agent Loop

開始 Agent 101

③ RAG 101 · 帶小抄進考場

Agent 常常要查資料，RAG 就是最常見的作法。用「閉卷考 vs 開卷考」比喻講清楚檢索（Retrieval）與生成（Generation）怎麼分工，以及建 RAG 跟建一般資料庫到底差在哪——關鍵字搜尋 vs 語意搜尋，一次玩懂。

⏱ 60 分鐘 · 7 個章節 · 語意搜尋實驗室
